# Describe It. Prompt It. Reflect On It

## Original idea
A virtual sticky note that lets you jot down ideas, daily schedules, or important reminders—and even doodle something fun—right on your computer desktop or smartphone home screen.

## Instructions for Opening or Running the Project
1. Download or clone this GitHub repository to your local computer.
2. Locate the file named `index.html`.
3. Double-click `index.html` (or right-click and choose "Open with" your preferred web browser like Chrome or Safari) to run and test the project.

## AI Tools Used & Selected Prompts
   AI Tool Used : Codex (ChatGPT)
（1）Selected Prompt 1 (Core Interaction & Dragging):
    When the user clicks the 'Pin to my screen' button, create a virtual sticky note on the page. Make sure the note is draggable anywhere on the screen using mouse drag-and-drop.

（2）Selected Prompt 2 (Playful Testing - Custom Shapes):
    Add options to customize the sticky note shapes. Can you generate playful shapes like a heart, a star, and a cat head using CSS?

（3）Selected Prompt 3 (Feature Fix - Deletion Mechanism):
    Add a visible delete button to the corner of each sticky note so users can remove it once the task is finished.

## Reflection
In this project, my goal was to create a simple virtual sticky note where users can quickly type notes, daily schedules, or fun reminders on the screen. The basic note-taking part matched my idea, but several interaction details did not work as I expected. At first, I wanted the stickers to be freely draggable anywhere on the screen, but they were completely static. Also, there was no way to delete a note, so completed tasks would just stay there and clutter the screen. To solve these problems, I tested the prototype and asked AI to add a delete button and fix the drag-and-drop feature. After these changes, the notes became much easier to organize, and users could clean up finished tasks smoothly.
During the building process, AI was very helpful as a coding assistant, helping me turn my ideas into real code step by step. However, AI could not tell me what a good user experience should feel like; I had to test the tool myself to see what was inconvenient and decide what features to prioritize, like the delete and drag functions. Looking back, a few problems are still unresolved. For example, if someone deletes a sticker by accident, there is no "undo" button to recover their notes. Also, the stickers are currently limited to the browser page instead of showing up on the actual phone home screen or computer desktop as real reminders. I hope to improve these two points in future versions.
